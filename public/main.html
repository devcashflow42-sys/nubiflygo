API

Conéctate por API en minutos

Automatiza tu flujo con tu propia API key: crea proyectos, sube archivos y consulta tus documentos directamente desde tu código.

  • Autentícate con una API key única por proyecto.
  • Sube y publica archivos con cURL, JavaScript o Python: dos peticiones y listo.
  • Respuestas en JSON con estados claros y predecibles.
nubiflygo.api / v1 
# 1. Sube el archivo a tu proyecto
curl -X POST https://nubiflygo.com/api/v1/files/upload \
  -H "Authorization: Bearer $NUBIFLYGO_API_KEY" \
  -F "file=@cancion.mp3" \
  -F "project_id=ID_DEL_PROYECTO"

# 2. Publícalo (usa el "id" de la respuesta)
curl -X PATCH https://nubiflygo.com/api/v1/files/ID_DEL_ARCHIVO \
  -H "Authorization: Bearer $NUBIFLYGO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"published": true}'

Preguntas frecuentes

Resuelve tus dudas antes de empezar

¿Qué tipos de archivos puedo subir?
Puedes publicar documentos de varios tipos dentro de cada proyecto: PDF, Word, imágenes, hojas de cálculo y archivos de texto, entre otros.
¿Dónde se guardan mis API keys?
Tus llaves se guardan por proyecto y se mantienen contigo. Las usas dentro de tu espacio y no se comparten con terceros.
¿Puedo tener varios proyectos a la vez?
Sí. Cada proyecto es un espacio independiente con sus propios archivos, notas, informes y llaves.
¿Necesito instalar algo?
No. NubiFlyGo funciona en el navegador. Abres tu espacio y empiezas a trabajar enseguida.
